# Python Learning Repository

## Overview
This repository contains Python learning exercises and examples covering fundamental to intermediate concepts.

## Topics Covered

### 1. **Python Basics** (`python/`)
- Introduction to Python
- Hello World and basic syntax
- Variables and data types

### 2. **Control Statements** (`python/control Statement/`)
- If/else statements
- Conditional logic
- Problem statements and exercises

#### Loops (`python/control Statement/loop/`)
- For loops
- While loops
- Nested loops
- Range function
- Loop control (break, continue)

#### Strings (`python/control Statement/String/`)
- String creation and manipulation
- String methods (find, replace, etc.)
- String indexing and slicing
- Alias and string checking methods

### 3. **Functions** (`function/`)
- Function definition and syntax (`def`)
- Function parameters and return values
- **Decorators** - wrapping functions with additional functionality
- **Generators** - using `yield` to create iterators

### 4. **Data Structures**

#### Lists/Methods (`methods.py/`)
- List creation
- List methods: `append()`, `insert()`, `pop()`, `remove()`, `extend()`, `clear()`, `sort()`, `reverse()`, `index()`, `count()`

#### Tuples (`Tuples/`)
- Tuple creation (immutable sequences)
- Tuple operations

#### Dictionaries (`dicitionary/`)
- Dictionary creation
- Dictionary methods: `get()`, `items()`, `popitem()`
- Dictionary comprehension
- Nested dictionaries
- Parameters and values
