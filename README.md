# Python Learning Repository

## Overview
This repository contains Python learning exercises and examples covering fundamental to intermediate concepts.

## Topics Covered

### 1. **Python Basics** (`python/`)
- Introduction to Python
- Hello World and basic syntax
- Variables and data types

### 2. **Control Statements** (`python/control Statement/`)
- If/else statements
- Conditional logic
- Problem statements and practice exercises
- Q&A examples and questions

#### Loops (`python/control Statement/loop/`)
- For loops and iterations
- While loops 
- Nested loops
- Range function
- Infinite loops (`infi.py`)
- Practice exercises (`p.py`, `p1.py`)
- Loop notes and documentation

#### Strings (`python/control Statement/String/`)
- String creation and manipulation
- String checking methods and validation
- String finding and searching
- Aliases and string operations
- String methods documentation and notes

### 3. **Functions** (`function/`)
- **Main concepts** (`main.py`) - function definition and basic syntax
- **Return statements** (`return.py`) - returning values from functions
- **Decorators** (`decorator.py`) - wrapping functions with additional functionality
- **Generators** (`decorator.py`) - using `yield` to create iterators
- **Lambda functions** (`lmd.py`) - anonymous functions for short operations
- Function notes and documentation (`functionn.txt`)

### 4. **Data Structures**

#### Lists/Methods (`methods.py/`)
- List creation and basic operations
- List methods organized by functionality:
  - **Adding items**: `append()`, `insert()`, `extend()`
  - **Removing items**: `pop()`, `remove()`, `clear()`
  - **Sorting & Organizing**: `sort()`, `reverse()`
  - **Searching & Counting**: `index()`, `count()`

#### Tuples (`Tuples/`)
- Tuple creation (immutable sequences) (`create.py`)
- Tuple operations and use cases
- Tuples notes and documentation (`tuples.txt`)

#### Dictionaries (`dicitionary/`)
- **Creating dictionaries** (`create.py`)
- **Updating dictionaries** (`update.py`)
- Dictionary notes and documentation (`dicitionary.txt`)

##### Dictionary Methods (`dicitionary/dicit_methon/`)
- `get()` - retrieve values safely (`get.py`)
- `items()` - iterate over key-value pairs (`items.py`)
- `popitem()` - remove and return items (`popitem.py`)
- Dictionary comprehension (`dict_compershision.py`)
- Nested dictionaries (`nsted.py`)
- Parameters and values (`parameters&values.py`)

### 5. **Object-Oriented Programming (OOP)** (`Oops/`)
- **Class basics** (`class.py`) - creating blueprints for objects
- **Creating objects** (`new.py`) - instances of classes
- **Self keyword** (`self.py`) - reference to the current object instance
- **Methods** - functions inside classes
- **Practice and projects** (`pr.py`)
- OOP notes and documentation (`oops.txt`)
