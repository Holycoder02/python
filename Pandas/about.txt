# what is Data Manipulation and Analysis?

Data Manipulation
 Defination: Changing, Organizing, or perpraing data make it useful and easier to understand.
 Goal: To clean, transform, and structure raw data for better usability.
 Example: 
    * Organizing a Grocery List : Sorting random items into categories like "fruits" or "dairy"
    * Fixing Errors in a Student Record : Corecting missing or worng grades.



Data Analysis
 Defination: Extracting patterns, trends and insights from the data to solve problem or make diesion
 Goal: To answer question or identify trends using the data
 Example:
   * Analysis Sales trends: Finding the month with highest revenue
   * Tracking Fitness Progress: Analysis daily steps and calories for ac

# key Differences Between Data Manipulation and Analysis

 Aspect               Data Manipulation                      Data Analysis

 focus           perpraingand cleaning data                Extracting insights from prepared data
 Goal          Organizing and structure raw data              Finding patterns, trends and solve problems
 Example      Fixing error in a dtudent's grade sheet           analyzing which student scored the highest
